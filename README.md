## O que é _tatu_?

O tatu-bola, quando sente perigo, se enrola e vira uma bola de casco duro. É exatamente isso que nosso aplicativo, **tatu**, faz com as suas senhas: guarda tudo num lugar protegido, cifrado e com acesso controlado.

> ⚠️ **Aviso:** o tatu é um sistema **didático**. Use apenas dados fictícios e nunca cadastre uma senha que você usa de verdade. Veja [por que ele não pode ser usado na vida real](#️-por-que-o-tatu-não-pode-ser-usado-na-vida-real).

**A dor principal da Luana é a fadiga.** São contas demais, e cada regra nova de senha parece um obstáculo.

**O risco que ela não enxerga:** hoje ela tem mais de 25 senhas iguais. Se a loja virtual mais insegura vazar, todas as outras ficam expostas.

**O que o tatu faz por ela:**

| A Luana precisa... | O tatu entrega |
|---|---|

| Parar de lembrar de 40 senhas | Um **gerador** de senhas fortes e um cofre para guardar todas |

| Confiar no que acontece com os dados | Um **histórico** de tudo o que foi feito, inclusive quando uma senha foi revelada |
| Tirar dúvidas sem caçar nos menus | A **tatuAI**, que responde perguntas em linguagem natural |

## Luana existe: a pesquisa por trás da persona

A Luana não é inventada do zero. A literatura mostra que **existe um mercado**: os jovens reconhecem a importância de ter senhas seguras, mas muitas vezes mantêm práticas inseguras.

| População estudada | O que sabem | Comportamento de risco relatado | Fonte |
|---|---|---|---|
| Crianças e escolares (3º ao 8º ano) | Entendem o controle de acesso e a proteção pessoal | Criam senhas fracas e previsíveis | Choong et al. (2019) |
| Adolescentes (13 a 16 anos) | Discutem ativamente métodos de recuperação | Compartilham senhas com amigos íntimos | Choong et al. (2019) |
| Estudantes do ensino superior | Reconhecem ameaças cibernéticas | Reutilizam senhas de forma sistemática e resistem a trocá-las | Alqahtani (2022) |
| Jovens em plataformas sociais | Conhecem critérios de complexidade | Trocam credenciais de propósito, para afirmação social | Akter et al. (2025) |

**O que isso diz sobre a Luana:**

- **Ela sabe que senha segura protege.** Crianças, adolescentes e universitários entendem o papel protetor das senhas, e a Luana também (Choong et al., 2019; Alqahtani, 2022; Ispussinov et al., 2026).
- **Saber não vira hábito.** Em uma avaliação com 189 estudantes, só 13% criavam senhas consideradas muito fortes (Choong et al., 2019). Entre universitários, é comum recusar a troca periódica e usar uma única credencial em várias contas por inconveniência (Alqahtani, 2022; Opoku et al., 2026).
- **Conveniência e conexão social pesam mais.** Muitos jovens compartilham senhas com amigos (Akter et al., 2025).
- **A fadiga é a raiz do problema.** Gerenciar dezenas de credenciais cansa e leva a escolher dados biográficos óbvios ou a anotar senhas em lugares inseguros (Jerbie et al., 2024; Opoku et al., 2026).

É por isso que o tatu foca em reduzir o esforço (gerador de senhas, cofre único) e em mostrar o risco de um jeito simples, sem exigir que a Luana vire especialista em segurança.

## O que tatu tem

| Requisito | Como o tatu cumpre |
|---|---|
| **CRUD de credenciais** | Adiciona, lista, edita e exclui credenciais (serviço, usuário/e-mail, senha, categoria, observações e data do último cadastro ou alteração). |
| **Senha escondida na tela** | Ao listar, aparecem só os dois primeiros caracteres e asteriscos (`ab*****`). Para revelar, a pessoa confirma com a senha da própria conta. |
| **Categorias** | Cinco categorias iniciais, cada uma com força mínima de senha. Dá para criar novas e definir a exigência delas. |
| **Análise de força** | Classifica a senha de 0 a 3 e explica o motivo. |
| **Detecção de risco** | Avisa em quais serviços a mesma senha já está em uso ao cadastrar ou editar. |
| **Registro de auditoria** | Registra as operações relevantes, com data, hora e usuário. O histórico é consultado pelo menu. |
| **Relatório de segurança** | Total de credenciais, fracas, repetidas, comuns e o tempo desde a última alteração de cada uma. |
| **Armazenamento** | Tudo é salvo em arquivos `.txt`, então os dados continuam entre uma execução e outra. |
| **Extra: gerador de senhas** | Cria senhas fortes (sempre nível 3). |
| **Extra: cifra das senhas** | As senhas são embaralhadas no arquivo com uma chave mestra. |
| **tatuAI** | Agente de IA que responde perguntas sobre os dados do usuário. |

## Como executar

### Requisitos

- Python 3.10 ou superior
- Biblioteca `groq`, usada **somente** pela tatuAI (exceção autorizada para o módulo `agente.py`)

### Passo a passo

**1. Defina a chave mestra.** Ela cifra as senhas e precisa existir no mesmo terminal em que o programa vai rodar.

```bash
# macOS / Linux
export CHAVE_MESTRA="uma-frase-secreta-qualquer"

# Windows (PowerShell)
$env:CHAVE_MESTRA="uma-frase-secreta-qualquer"
```

> Se a chave não estiver definida, o programa para com `AttributeError: 'NoneType' object has no attribute 'encode'`.
> **Não troque a chave depois de cadastrar senhas:** as senhas antigas deixam de ser legíveis.

**2. (Opcional) Ative a tatuAI.** O resto do sistema funciona sem isso.

```bash
pip install groq
```

Crie um arquivo `.env` na pasta do projeto:

```
GROQ_API_KEY=cole_sua_chave_aqui
```

A chave é gratuita em [console.groq.com](https://console.groq.com). Nunca envie o `.env` para o GitHub.

**3. Execute.**

```bash
python3 main.py
```

## Como usar

### Menu de login

```
1 - Cadastrar conta
2 - Entrar na conta
3 - Sair
```

Ao cadastrar a conta, você pode digitar uma senha ou deixar o tatu gerar uma senha forte.

### Menu principal

```
1  - Adicionar credencial
2  - Ler credenciais
3  - Atualizar credencial
4  - Consultar categorias
5  - Cadastrar categoria
6  - Excluir credencial
7  - Falar com tatuAI
8  - Consultar histórico (log)
9  - Resumo de segurança
10 - Sair
```

- **Adicionar:** informe serviço, usuário/e-mail e categoria (digite o número da lista). Escolha entre gerar uma senha forte ou digitar a sua. Se ela não atingir a força mínima da categoria, o tatu pede outra.
- **Ler:** mostra cada credencial com a senha escondida e pergunta se você quer revelá-la. Para revelar, digite a senha da sua conta.
- **Atualizar e excluir:** escolha o serviço pelo número na lista. Ao atualizar, a data de alteração é renovada.
- **tatuAI:** escreva uma pergunta, por exemplo _"quantas credenciais são da categoria banco?"_. O agente foi instruído a não mostrar usuários, serviços nem senhas.
- **Resumo de segurança:** mostra os totais e o tempo desde a última alteração de cada credencial.

## Decisões de segurança

### Classificação de força da senha

| Nível | Nome | Critério |
|:-:|---|---|
| 0 | Muito fraca | Menos de 6 caracteres |
| 1 | Fraca | 6 ou mais caracteres, com número ou letra minúscula |
| 2 | Média | 6 ou mais caracteres, com maiúscula, minúscula e número |
| 3 | Forte | Tudo do nível 2 e pelo menos um símbolo (`! @ # $ % & * - _ ? / + =`) |

**Por que esses critérios?** Comprimento e variedade de caracteres aumentam o número de combinações que um atacante precisa testar. Escolhemos 6 caracteres como piso porque senhas menores caem em segundos. E o tatu sempre explica o resultado em texto: a ideia é Luana entender como melhorar a senha, e não só receber uma nota.

### Categorias e exigência mínima

| Categoria | Força mínima | Motivo |
|---|:-:|---|
| banco | 3 (forte) | Acesso a dinheiro |
| estudos | 3 (forte) | Dados pessoais e acadêmicos |
| trabalho | 2 (média) | Dados profissionais |
| redes sociais | 2 (média) | Risco de golpes em nome do usuário |
| outros | 1 (fraca) | Baixo impacto |

A pessoa pode criar categorias novas e escolher a exigência de cada uma.

### Proteções implementadas

- **Senhas cifradas no arquivo.** Cada senha é guardada em hexadecimal, cifrada com uma chave derivada de `CHAVE_MESTRA`. Sem a chave, o arquivo não é legível.
- **Chaves fora do código.** A chave mestra fica em variável de ambiente e a chave da API no `.env`, nunca escritas no código-fonte.
- **Senha escondida na tela**, com revelação só depois de confirmar a senha da conta.
- **Arquivo por usuário no `.gitignore`.** Quando o arquivo de credenciais de alguém é criado, o nome dele é adicionado automaticamente ao `.gitignore`.
- **Detecção de reutilização.** O tatu mostra em quais serviços a mesma senha já está em uso.
- **Auditoria.** Cada ação relevante é registrada, inclusive tentativas falhas de revelar senha.

### Por que um sistema de segurança registra o que foi feito?

O estado atual mostra **o que existe**, mas não **o que aconteceu**. Se uma senha foi revelada ou alterada sem o dono saber, só o histórico permite descobrir quando, quem e em qual serviço. Por isso cada usuário consulta o próprio histórico pelo menu.

## Por que tatu não pode ser usado na vida real

1. **A cifra é caseira.** Foi feita para ensinar e nunca passou por uma auditoria. Gerenciadores reais usam algoritmos padronizados e revisados (como AES) e derivação de chave com custo computacional alto.
2. **A chave mestra fica numa variável de ambiente.** Quem tem acesso ao computador consegue lê-la e decifrar tudo. Um cofre de verdade deriva a chave de uma senha mestra que só o usuário conhece.
3. **A senha da conta é recuperável.** O login usa a mesma cifra reversível. O correto é guardar apenas um _hash_ com sal, que não pode ser desfeito.
4. **O histórico pode ser editado.** Quem tem acesso à pasta consegue apagar ou alterar linhas do `log.txt`.
5. **Não há bloqueio contra tentativas repetidas** de senha.
6. **A tatuAI envia dados para fora.** O conteúdo do arquivo de credenciais (serviços, usuários e senhas já cifradas) vai para a API da Groq para responder a pergunta. Em um cofre real, esses dados nunca sairiam do dispositivo.
7. **Tudo é texto no terminal**, sem proteção do sistema operacional contra outros programas que leiam os arquivos.
